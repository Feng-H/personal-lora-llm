# FAQ

## 数据与采集

**Q: 为什么不删语气词、口头禅、重复句？**
A: 这些正是风格。「保真优先」是本项目区别于所有同类项目的铁律：机器只剔除纯噪声（乱码/链接/表情占位/系统消息/无意义单字碎片），绝不润色、不标准化、不强制去重。你刻意重复三遍的强调句会被完整保留。

**Q: 三种采集方式选哪个？**
A: 推荐组合拳——问卷冷启动（30 分钟打底 30-80 条）→ 日常和 AI 聊天自然积累（王牌，有主动补齐）→ 有微信/QQ 历史记录就批量抽取（存量复用）。

**Q: 样本要多少条？**
A: ≥70 条可训练（基础版风格）；≥120 条为最优体量（达到后主动采集自动关闭）。多场景模式每个场景至少 45 条且强制校验。

**Q: 主动找话题会不会很烦？**
A: 有严格限流：单轮会话最多 1 次、单日最多 3 次、连续 2 次无视自动永久降级被动、达标自动关闭。且发起方式是「像朋友随口提起」，无问卷感。

**Q: 为什么我的"嗯""哦"也算样本，还被提示"敷衍短句过多"？**
A: 它们是风格的一部分，会保留；但全是短句会让模型学不到你的完整表达。结构缺陷检测就是为此存在——AI 会主动发起需要深度表达的话题来补齐长句样本。

## 技术边界

**Q: 为什么推理阶段没有 RAG / 向量检索 / 外挂记忆？**
A: 本项目明确定义：RAG 仅作为训练集素材预处理工具（IM 历史抽取）。最终成品 = 基座 + LoRA 纯模型推理。模型真正"学会"了你的风格，而不是检索拼接你的话术——这是「复刻」与「复读机」的本质区别。

**Q: LoRA 学到的是什么？基座负责什么？**
A: LoRA 学你的说话风格、句式、语气、态度、沟通习惯；基座保留通用知识与逻辑理解。r=16 + epoch 2-4 + 早停，学风格不死记硬背。

**Q: 数据格式是什么？**
A: 全链路统一 Qwen 标准 messages jsonl：`{"messages": [{"role": "system"/"user"/"assistant", ...}]}`，多轮对话完整打包。

## 训练与部署

**Q: 没有显卡能训练吗？**
A: 能。Kaggle 免费 T4，Qwen 6B + 4bit QLoRA 约 2-3 小时跑完。

**Q: Mac M1 8G 能跑吗？**
A: 能。Q4_K_M 量化后整机占用约 3.5G，活动监视器全绿（参考姊妹项目《通过 Colab/Kaggle 学习模型微调》的实测账本）。

**Q: 训练完怎么迭代？**
A: 继续攒样本 → 重新导出 → 再跑一次 Notebook 即可。数据集 jsonl 会自动带上最新样本。

## 隐私

**Q: 作者能看到我的数据吗？**
A: 不能。没有服务端、没有统计上报。见 `docs/privacy.md`。

**Q: 上传 Kaggle 安全吗？**
A: 数据集设为 Private 只属于你的账号；介意的话可在导出前用审核面板删除敏感样本（清洗已自动给隐私明文打码并标记【风险】）。
