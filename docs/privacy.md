# 隐私与免责声明

## 数据归属（铁律）

- **作者不持有、不中转、不上传、不存储任何用户数据**
- 所有聊天记录、问卷回答、数据集、LoRA 权重 100% 位于你自己的电脑 / 你自己的 Kaggle 账号
- 本仓库 `data/` 目录已被 `.gitignore` 排除，永远不会进入 git

## 各环节的隐私边界

| 环节 | 数据流向 | 说明 |
| --- | --- | --- |
| 问卷 / 对话采集 | 浏览器 → 本地 Streamlit → 本地 jsonl | 不出本机 |
| 对话 AI 采访者 | 本机 → **你自己配置的本地 LLM**（Ollama 等） | 默认 localhost，不联网 |
| IM 抽取 Embedding | 本机（`BAAI/bge-small-zh-v1.5` 本地推理） | 首次下载模型会访问 HuggingFace，之后全离线 |
| IM 抽取 LLM 质检 | 本机 → 你自己的本地 LLM | 同上 |
| 训练 | 你上传到你**自己的 Kaggle 私有数据集** | Kaggle 侧遵守其隐私政策 |
| 推理 | 本机（Ollama / MLX / llama.cpp） | 纯离线 |

## 隐私明文处理

清洗流水线自动检测并**打码**（不删除）：

- 手机号 / 身份证 / 邮箱 / 银行卡 / 链接

打码样本会打上【风险】标记，供你在审核面板复核。**最终决策权永远归你。**
